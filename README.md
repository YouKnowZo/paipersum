# PaiperSum - Legal Document Analyzer

> Analyze contracts, leases, and agreements in 3 seconds. Find hidden fees, risky clauses, and auto-renewals before you sign.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Deploy to Vercel
vercel
```

## 📁 Project Structure

```
paipersum/
├── api/              # Vercel serverless functions
│   └── analyze.js    # Document analysis API
├── frontend/         # React frontend
├── backend/          # Express backend
├── server/           # Legacy server files
└── vercel.json       # Vercel configuration
```

## 🎯 Features

- **Instant Analysis** - Get risk scores in 3 seconds
- **Hidden Fee Detection** - Find cancellation fees, processing charges, etc.
- **Risky Clause Identification** - Spots indemnification, arbitration, auto-renewals
- **Plain English Explanations** - Understand what you're signing
- **PDF Export** - Download professional reports
- **100% Private** - Documents deleted after 24 hours

## 🔧 Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express, Vercel Serverless
- **Database:** PostgreSQL (via Vercel Postgres)
- **Deployment:** Vercel
- **Analytics:** Google Analytics 4
