## 🚀 HOW IT WORKS

### 1. Always Watching (Background)
- Floating button in bottom-right corner
- Monitors for ToS/Privacy/Cookie popups
- Doesn't interfere with browsing
- Only activates when needed

### 2. Auto-Detection
Looks for:
- "Terms of Service"
- "Privacy Policy"
- "Cookie Policy"
- "By clicking Accept"
- "I agree to"
- Modal popups
- Cookie banners
- Consent forms

### 3. Instant Analysis
- Extracts text automatically
- Sends to PaiperSum API
- Gets risk score + issues
- Shows in floating panel
- All in 3 seconds

### 4. Clear Results
Shows:
- Risk level (Low/Medium/High)
- Decision (Accept/Be Careful/Don't Accept)
- Key issues (top 5)
- What you should do
- Link to full analysis

## 🔒 PRIVACY & SECURITY

### What We Do:
- ✅ Only analyze when ToS detected
- ✅ Send text to API, get results
- ✅ Don't store documents
- ✅ Don't track browsing
- ✅ Don't sell data
- ✅ Open source code

### What We Don't Do:
- ❌ Read your passwords
- ❌ Access banking info
- ❌ Track browsing history
- ❌ Share user data
- ❌ Inject ads

### Permissions Needed:
- `activeTab`: Read current page (only when ToS detected)
- `storage`: Save settings locally
- `host_permissions`: Access websites (for analysis)

**All justified and transparent.**
