## Remaining Configuration Tasks

### Items You Need to Complete

#### 1. Stripe API Keys

**Action Required:**
1. Go to https://dashboard.stripe.com/apikeys
2. Copy your **Publishable key** (pk_test_... or pk_live_...)
3. Copy your **Secret key** (sk_test_... or sk_live_...)

**Where to Add:**
```
Frontend (.env in /apps/web):
VITE_STRIPE_PUBLIC_KEY=pk_test_YOUR_KEY_HERE

Backend (.env in /apps/api):
STRIPE_SECRET_KEY=sk_test_YOUR_KEY_HERE
```

**Create Stripe Products:**
1. Go to Products tab in Stripe
2. Create product "PaiperSum Pro"
3. Set price: $20/month
4. Copy Price ID (price_xxx)
5. Add to backend environment

**Set Up Webhooks:**
1. Go to Developers → Webhooks
2. Add endpoint: `https://your-backend-url.com/stripe/webhook`
3. Select events: checkout.session.completed, subscription.*
4. Copy webhook secret (whsec_...)
5. Add to backend environment as STRIPE_WEBHOOK_SECRET

---

#### 2. AI API Keys

**OpenAI:**
1. Go to https://platform.openai.com/api-keys
2. Create new key
3. Add to backend: `OPENAI_API_KEY=sk-...`

**Anthropic (Optional):**
1. Go to https://console.anthropic.com/
2. Create API key
3. Add to backend: `ANTHROPIC_API_KEY=sk-ant-...`

---

#### 3. Domain DNS Configuration

**If you own paipersum.com:**

1. Log in to your domain registrar (Namecheap, GoDaddy, etc.)
2. Go to DNS Management
3. Add these records:

```
Type: A
Host: @
Value: 76.76.21.21
TTL: Automatic

Type: CNAME
Host: www
Value: cname.vercel-dns.com
TTL: Automatic
```

4. Wait 1-24 hours for propagation
5. Verify in Vercel dashboard

#### 4. Database Setup

**Choose One:**

**Option A: Render PostgreSQL (Free)**
