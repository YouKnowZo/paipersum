1. **AI is rule-based** - Using regex patterns, not advanced ML models (would need GPT-4 API or fine-tuned BERT)
2. **Mock authentication** - localStorage-based, not production-ready
3. **No database** - Everything in memory (need PostgreSQL/MongoDB)
4. **Limited file formats** - No images, no spreadsheets yet
5. **No tests** - Would fail enterprise procurement without test coverage
6. **Stripe not connected** - Payment flow ready but not integrated
7. **No collaboration** - Single-user only currently
8. **English only** - No multi-language support
