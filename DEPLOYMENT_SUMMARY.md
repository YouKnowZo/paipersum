## 🔧 Quick Fix for Current Error

**Error**: "Root Directory 'frontend' does not exist"

**Solution**:
1. Go to Vercel Dashboard: https://vercel.com/dashboard
2. Select your project
3. Go to **Settings** → **General**
4. Find **Root Directory** field
5. **Clear it** (leave empty)
6. Click **Save**
7. Go to **Deployments** tab
8. Click **Redeploy** on latest deployment

## ⚠️ Common Issues

### Issue 1: "Root Directory 'frontend' does not exist"
**Cause**: Vercel project settings have root directory set incorrectly  
**Fix**: Clear root directory in Vercel settings (see Quick Fix above)

### Issue 2: Build fails with "cannot find module"
**Cause**: Build command not running from correct directory  
**Fix**: Ensure vercel.json is in repo root and Root Directory is empty

### Issue 3: Multiple conflicting deployments
**Solution**: 
1. Keep only one active Vercel project
2. Delete unused projects in Vercel dashboard
3. Use vercel.json for configuration (single source of truth)

## 🔄 Backup Configuration

If primary deployment fails, use these manual settings:

**Vercel Manual Config** (if vercel.json fails):
- Root Directory: `apps/web`
- Build Command: `npm install && npm run build`
- Output Directory: `dist`
- Framework: Vite

**Railway Manual Config** (if railway.json fails):
- Root Directory: `apps/api`
- Build Command: `pip install -r requirements-deploy.txt`
- Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
