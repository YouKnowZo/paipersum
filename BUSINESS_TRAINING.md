# Solo Founder Execution Guide (Focused)

## Weekly cadence
- Monday: metrics review, priority pick (1 growth, 1 product), plan.
- Tue–Thu: build/ship. Block 4h deep work daily.
- Friday: publish learnings thread + demo video; partner outreach.

## Non‑negotiables
- Ship user‑visible value weekly.
- Talk to 3 users/week (interviews or support calls).
- Track one north‑star metric (weekly active analyzers).

## Decision filters
- Increases activation, retention, or revenue this month?
- Can it be done in <1 week? If not, cut scope.
- Does it reduce support burden?

## Core funnels
- SEO/Examples -> Analyze -> First Win -> Account Created -> Upgrade
- Extension install -> Prompt to Analyze -> Save/Reminder -> Return

## Habits
- Record a 2–5 min Loom for every feature shipped.
- Maintain a changelog and tweet it.
- Keep a living list of top 10 user requests.
