## 🐛 TROUBLESHOOTING

### "Animations not working"
```bash
# Make sure tailwind.config.cjs has animations
# Restart dev server:
docker-compose restart web
```

### "Chatbot not showing"
```tsx
// Make sure FloatingChatbot is imported in App.tsx:
import FloatingChatbot from './components/FloatingChatbot'

// And rendered:
<FloatingChatbot />
```

### "Examples not analyzing"
```bash
# Check API is running:
curl http://localhost:8000/health

# Should return: {"status":"healthy"}
```

### "Styles look broken"
```bash
# Rebuild tailwind:
cd apps/web
npm run build
docker-compose restart web
```
